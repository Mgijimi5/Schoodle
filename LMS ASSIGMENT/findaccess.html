File Access and Management

Duration: Week 1 - Week 3

0%
📚 Topic Overview

This topic introduces learners to file management. You will learn how files and folders are created, organised and stored. You will also develop practical skills for managing digital information effectively.

🎯 Learning Outcomes
  • Identify different types of files and folders.
  • Create and organise folders.
  • Rename, move, copy and delete files.
  • Understand different storage devices.
  • Apply good file management practices.
